# Compile Dependencies

This folder must contain two jars that are **not** redistributed in this repository
(for licensing reasons - Forbidden & Arcanus is All Rights Reserved):

- `forbidden_arcanus-2.6.1.jar` - the unmodified Forbidden & Arcanus mod jar
  (CurseForge / Modrinth release, or built from source)
- `valhelsia_core-neoforge-1.21.1-1.1.5.jar` - Valhelsia Core, the mod dependency
  (CurseForge / Modrinth release)

Both are only needed to compile; they are not included in the built addon jar.
